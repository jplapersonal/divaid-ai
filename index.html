Beating the 100MB IOx limit.

Cisco CW917X APs have powerful ARM64 CPUs, but `cgroups` restrict memory to roughly 100MB. A 1B parameter model needs 2.2GB. Here is the math behind the magic.

01. Quantization

INT4 GGUF

We compress Llama-3.2-1B weights to 4 bits (Q4_K_M). Total model footprint plummets from 2.2GB to ~800MB with near-zero perplexity loss.

02. Pipeline Parallelism

Layer Slicing

The Llama-3.2-1B model contains 16 Transformer Layers. Instead of loading it fully, we slice the 800MB model horizontally across the network.

Total Size 800 MB
Total APs ÷ 16 Layers
Memory per Node ~50 MB
